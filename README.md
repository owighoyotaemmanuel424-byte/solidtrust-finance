# SolidTrust Finance

**Building Trust. Growing Wealth.**

SolidTrust Finance is a calm, transparent fintech experience for everyday savers and small borrowers.

## Stack
- Next.js 14 App Router
- TypeScript
- Tailwind CSS
- shadcn/ui-compatible primitives
- Vercel-ready

## Current foundation
- Responsive public landing page
- Savings and responsible-borrowing positioning
- Login and registration entry points
- Trust-focused visual system

## Next build phases
1. Database and secure authentication
2. Customer dashboard and accounts
3. Savings goals and deposits
4. Loan applications, underwriting workflow, and repayments
5. Transactions and notifications
6. Admin/operations console
7. Security, audit logging, testing, and production deployment

Never store real financial credentials or secrets in source control.
